Problem Statement & Background

The Campus Placement Challenge

1. Curriculum Disconnect

Academic coursework teaches fundamentals but leaves gaps in modern stacks (Docker, REST APIs, GenAI RAG, Cloud CI/CD) expected by TCS Prime, AWS, and Cognizant.

2. Lack of Structured Milestones

Students face tutorial overload and burnout without granular, actionable checklists or verifiable project portfolios.

3. Placement Verification

Placement officers lack a single-source verification dashboard to track verified skill proficiencies and student readiness benchmarks.

Technical Architecture

Client-Server Full Stack Architecture

Frontend Layer (Client)

• Vanilla HTML5 + CSS3 Design System
• Vanilla JS Single Page Application (SPA)
• Zero build tools or NPM dependencies
• Responsive flex/grid and SVG gauges

Backend Layer (Server)

• Python 3.11+ / Flask Framework
• RESTful JSON API endpoints
• Werkzeug PBKDF2/scrypt encryption
• Gunicorn WSGI multi-threading

Database Layer (Storage)

• Embedded SQLite 3 relational engine
• Strict PRAGMA foreign_keys = ON
• Normalized tables with CHECK constraints
• Atomic updates via ON CONFLICT

Quality Assurance

Security, Testing & Validation

✅ Cryptographic Security

Passwords encrypted with salted PBKDF2/scrypt hashes. Session cookies secured against unauthorized tampering.

✅ Concurrency & Performance

Gunicorn WSGI configured with multi-threaded workers (`--workers 2 --threads 4`) ensuring fast response times under 50ms.

✅ Idempotent State Updates

SQLite upserts prevent duplicate progress entries during rapid clicking of module checkpoints.

✅ 100% Viewport Frame Fitting

Tested across mobile, 1366px laptops, and print engines ensuring zero cutoffs or vertical line clipping.
